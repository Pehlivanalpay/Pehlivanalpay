# Görsel kaynakları

Saha fotoğrafları (`public/images/` içindeki diğer dosyalar) ELIS360 NEWS arşivinden / müşteri tarafından sağlandı.

Stok görseller — [Pexels Lisansı](https://www.pexels.com/license/): ücretsiz, ticari kullanım serbest, atıf zorunlu değil.
Görsel kendi başına (değiştirilmeden) satılamaz; kişileri olumsuz/yanıltıcı biçimde gösterecek kullanım yapılmaz.

| Dosya | Kullanım | Kaynak |
|---|---|---|
| `reji.jpg` | Prodüksiyon sayfası ana görsel | https://www.pexels.com/photo/busy-workers-working-during-live-broadcast-4472346/ (16:9 kırpıldı) |
| `marka-film-seti.jpg` | Marka & PR sayfası ana görsel | https://www.pexels.com/photo/behind-the-scene-of-video-recording-of-a-man-in-blue-polo-sitting-on-a-chair-6847073/ (16:9 kırpıldı) |

Kendi çekiminiz geldiğinde dosyayı aynı adla değiştirip `npm run images` çalıştırmanız yeterli.
